3. 형상 관리

L1의 산출물은 스냅샷 단위로 불변이다.

snapshot_id — Open Targets 릴리스 버전에 종속
릴리스 교체는 신규 스냅샷 생성이며, 기존 스냅샷을 덮어쓰지 않는다
다운로드 원본의 체크섬을 기록해 재현성을 확보한다
스냅샷 간 표적 ID 안정성을 검증한다 (Ensembl ID 기준, HGNC 심볼 변경 이력 포함)

E1 평가가 구 릴리스를 피처로, 신 릴리스를 라벨로 사용하므로 복수 스냅샷의 동시 보존이 전제다.

5. 스키마 검증
검증 항목	처리
필수 필드 존재	누락 시 적재 중단
타입 일치	불일치 시 적재 중단
값 범위	이탈 시 경고 기록 후 적재
결측	NA로 유지. 0 치환·평균 대치 금지
ID 정규화	Ensembl gene ID를 기본 키로, HGNC 심볼은 별칭

6. 수집 방식
① fetch      원본 그대로 내려받아 보존 (변형 금지)
                └ 체크섬 기록, 이후 재다운로드 없이 재처리 가능
② normalize  ID 정규화, 결측 표기 통일, 컬럼명 표준화
                └ 원본은 건드리지 않고 새 파일로 산출
③ load       스키마 검증 후 질의 계층에 적재
                └ 검증 실패 시 여기서 중단

import httpx, hashlib
from pathlib import Path

def fetch(url: str, dest: Path) -> str:
    dest.parent.mkdir(parents=True, exist_ok=True)
    h = hashlib.sha256()
    with httpx.stream("GET", url, timeout=None, follow_redirects=True) as r:
        r.raise_for_status()
        with open(dest, "wb") as f:
            for chunk in r.iter_bytes(1 << 20):
                f.write(chunk); h.update(chunk)
    return h.hexdigest()
