# 염증성관절염 표적 가설 생성 에이전트 문서

해당 문서는, 염증성 관절염군 특화 신약개발 Agent 개발을 위해 작성되었으며, Agent의 목표와 목적, 기본적인 구조와 구성요소를 정리한 문서이다. 해당 구성 요소들을 바탕으로 AI Agent를 개발한다.

수정일: 2026-08-05

---

## 0. 요약

표현형으로 정의된 질환에서 검증된 표적이 이미 존재하는데도 상당 비율의 환자가 치료에 실패하는 경우, 병목은 표적의 부재가 아니라 **환자–기전 매칭의 부재**다. 본 아키텍처는 표적 발굴 문제를 **분할(partition) 발견과 표적 발굴의 결합 문제**로 재정의한다.

핵심 설계 조작은 세 가지다.

1. **환자 분할을 잠재변수로 명시**하고 파이프라인 전 단계를 관통하는 일급 객체로 전달한다.
2. 각 층을 데이터 소스가 아니라 **인식론적 역할**로 정의해, 질환이 바뀌어도 구현체만 교체하면 되도록 한다.
3. 출력을 목록이 아니라 **반증 가능한 튜플** `(서브타입, 경로, 바이오마커, 표적)`로 고정한다.

아키텍처 위상 자체는 기존 표적 가설 에이전트(OriGene, RegNetAgents 계열)와 크게 다르지 않다. 차별점은 **출력 스키마와 순위화 목적함수**에 있다.

## 1. 문제 유형 정의

### 1.1 적용 대상

> 기전이 아니라 표현형(증상·징후·자가항체·영상)으로 정의된 질환에서, 검증된 표적과 시판 치료제가 이미 존재하나 상당 비율의 환자가 반응하지 않는 경우

이 조건이 중요한 이유는, 진단명이 **기전의 이름이 아니라 증후군의 이름**이기 때문이다. 하나의 이름표 아래 구동 기전이 서로 다른 환자들이 묶여 있고, 이 잘못된 묶음이 아래로 내려가면서 세 층위를 연쇄적으로 망가뜨린다.

### 1.2 잘못된 묶음이 일으키는 세 가지 실패

**① 분석 층위 — 평균이 신호를 지운다 (본 설계의 출발점)**

"환자군 vs 대조군" 차등발현 분석은 기전이 다른 환자들을 평균 낸다. 전체의 30%에서만 활성화된 경로는 나머지 70%에 희석되어 통계적으로 관측 불가능해진다.

> 층화는 임상적 편의가 아니라 **분석이 무언가를 탐지하기 위한 전제조건**이다. 환자 이질성이 크고 서브그룹의 효과 방향이나 크기가 다를 경우, 전체 환자 평균 분석에서는 서브그룹 특이 신호가 희석되거나 왜곡될 수 있다.

**② 시험 층위 — 좋은 약이 통계 때문에 죽는다**

경로 P를 겨냥한 약을 전체 환자에 투여하면 P가 구동하는 소수에서만 효과가 나고 평균에 묻힌다. 약은 유효한데 시험이 실패한다. 더 나쁜 것은 그 표적이 업계에서 "검증된 실패"로 낙인찍혀 재도전이 어려워진다는 점이다. 층화 실패가 표적 하나를 영구 폐기시킨다.

**③ 자산 층위 — 신규 양식은 층화 없이 배치 불가능하다**

세포치료제나 이중·삼중특이항체처럼 전신 부담이 큰 양식은 반응 가능성이 낮은 환자에게 투여하는 것이 윤리적·규제적으로 정당화되지 않는다. 선별법이 없으면 약이 승인돼도 처방되지 않는다.

### 1.3 핵심 구조 — 분할은 잠재변수다

```
서브그룹 특이적 표적  ←  분할을 조건으로 걸어야만 관측됨
        ↕
분할의 타당성        ←  치료 반응 신호로만 검증됨
```

둘이 서로를 요구한다. 일반적인 표적 발굴 에이전트가 이 문제를 풀지 못하는 이유는 분할을 변수로 두지 않고 질병을 단일 집단으로 가정하기 때문이다.

### 1.4 문제 형식의 재정의

```
기존 형식:
    질병 D  →  순위화된 표적 목록 [T₁, T₂, T₃, ...]

본 아키텍처:
    질병 D + 기존 치료 집합 {t₁ ... tₙ}
        →  튜플 집합 {(S, P, B, T*)}

            S   환자 부분집합 (서브타입)
            P   해당 부분집합의 구동 경로
            B   S를 식별하는 판별 바이오마커
            T*  겨냥할 표적
```

## 2. 왜 에이전트인가

먼저 경계를 분명히 한다. **계산 자체는 에이전트가 필요 없다.** 클러스터링, 차등발현, 멘델 무작위화는 결정론적 파이프라인으로 구현하는 편이 재현성·감사가능성 모두에서 낫다.

LLM 에이전트가 대체 불가능한 지점은 셋이다.

### 2.1 판단 지점이 조합적으로 폭발한다

클러스터 해상도, "불응 연관"으로 인정할 임계, 다음 단계로 승급시킬 후보 선정 — 전부 정답이 없는 선택이고 각각에서 결과가 갈린다. 숙련된 분석가가 수개월에 걸쳐 내리는 결정이다. 에이전트는 이 분기를 다수 탐색하고 각 선택에 근거를 부착할 수 있다.

### 2.2 반박 근거가 DB가 아니라 산문에 있다 (가장 결정적)

"이 표적은 특정 시험에서 실패했다"까지는 구조화 DB 조회로 해결된다. 그러나 **왜** 실패했는지 — 용량, 환자군 선정, 기전 오류 중 무엇인지 — 는 논문 고찰과 시험 보고서 본문에 서술형으로만 존재한다.

> 이 구분이 결정적인 이유: 실패 원인이 **환자군 선정**이라면 그 표적은 배제 대상이 아니라 **오히려 최우선 후보**다(§1.2 ②의 희석 문제). 기전이 틀려서 실패한 것과 정반대 결론이며, 텍스트를 읽어야만 판별된다. 어떤 통계 프레임워크로도 대체되지 않는다.

### 2.3 이질적 증거의 화해

"클러스터 7에서 상향 조절" + "MR 추정치 OR 0.92" + "2상 실패 이력" — 이 셋을 단일 판단으로 통합할 수학적 방법이 없다. 언어 작업이다.

> ⚠️ **경계 원칙**
> 계산층은 결정론적 파이프라인, 판단·증거해석층은 에이전트. 이 경계가 흐려지면 재현 불가능한 시스템이 된다. 에이전트가 통계를 직접 "판단"하게 두는 순간 환각과 확증편향이 유입된다.

## 3. 아키텍처

### 3.1 입력

문헌 기반 에이전트(예: Robin)가 **질병명**을 입력받는 것과 달리, 본 아키텍처는 **범위가 좁혀진 임상 실패 진술**을 받는다.

```
[필수] 실패 진술
    "치료 t₁, t₂에 모두 불응하는 질환 D 환자를 위한
     새 표적 후보를 제시하라"

[선택] 제약조건
    - 성약성(druggability) 요건
    - 표적 국재 (세포외 한정 등, 양식 결정에 연동)
    - 기존 임상 실패 이력 표적의 취급 방침
    - 최소 근거 수준 (Layer 3 통과 필수 여부)
```

이 진술이 전 층을 관통하는 필터가 된다. "불응"이라는 조건이 Layer 1에서 볼 환자군과 Layer 2에서 설명해야 할 약효 패턴을 동시에 결정한다.

### 3.2 층을 데이터가 아니라 역할로 정의

이것이 일반화의 핵심 조작이다. 층을 데이터 소스로 정의하면 질환이 바뀔 때마다 아키텍처가 깨진다. **인식론적 역할로 정의하면 데이터는 교체 가능한 플러그인이 된다.**

---

#### Layer 1 — 분할 발견 (Partition Discovery)

| 항목 | 내용 |
|---|---|
| 역할 | 진단명 아래 숨은 기전적 하위 집단을 찾는다 |
| 요구 | 병변 부위의 고해상도 분자 데이터 (혈액만으로는 대개 불충분) |
| 출력 | 후보 유전자·세포집단 + **서브타입 정의 객체** |
| 구현체 예시 | 활막 scRNA-seq, 장 점막 생검, 신장 생검, 유도객담, 공간전사체 |

이 층의 출력인 서브타입 정의는 이후 모든 층에 전달되는 **상태 객체**다. 후처리 필터가 아니다.

#### Layer 2 — 대조 감독 (Contrastive Supervision)

| 항목 | 내용 |
|---|---|
| 역할 | **이미 알려진 약효 차이를 무료 레이블로 사용해** 후보를 판별한다 |
| 요구 | 차등적 반응 패턴이 기록된 대조 집합 |
| 출력 | 특이성 라벨 + 기존 임상 근거와의 정합성 판정 |

대조 집합은 무엇이든 될 수 있다.

- **자매 질환 간** — 같은 계열 질환에서 동일 약물의 효능이 갈리는 경우
- **반응자 vs 비반응자** — 종적 데이터가 확보된 경우
- **같은 표적 · 다른 양식** — 항체 억제 vs 세포치료제 제거
- **성공 시험 vs 실패 시험** — 공개 임상시험 결과 대조

> 원리는 하나다. **약효가 갈린 지점에는 이미 답이 일부 적혀 있다.** 이를 지도학습의 레이블처럼 사용한다.

#### Layer 3 — 직교 인과 정박 (Orthogonal Causal Anchor)

| 항목 | 내용 |
|---|---|
| 역할 | 상관을 인과로 승격하거나 기각한다 |
| 요구 | **Layer 1·2와 독립된 증거원** — 독립적이지 않으면 같은 편향을 공유해 검증이 성립하지 않는다 |
| 출력 | 인과 추정치 + 방향 + 가정 위배 여부 |
| 구현체 예시 | 인간 유전학(GWAS × QTL 멘델 무작위화), CRISPR 섭동 스크린, 멘델성 질환 표현형, 약물 안전성 신호 |

Layer 1·2는 전부 상관관계다. 병변에서 어떤 유전자가 고발현된다는 것은 그것이 원인이라는 뜻이 아니라 염증·손상의 **결과**일 수도 있다. 이 층이 방향성을 부여한다.

> 유전학은 여러 구현체 중 하나일 뿐이다. GWAS 검정력이 부족한 질환에서는 섭동 스크린이나 안전성 신호로 대체한다. 예컨대 특정 표적을 억제했을 때 나타난 부작용은 그 표적의 생물학적 역할에 대한 인간 대상 증거다.

#### 횡단 Layer — 적대적 증거 수집 (Adversarial Evidence)

| 항목 | 내용 |
|---|---|
| 역할 | 후보를 **반박하는** 증거를 능동 탐색 |
| 요구 | 전문 텍스트 독해 (§2.2) |
| 출력 | 반박 근거 목록 + 기각 사유 |

모든 층에 걸쳐 상시 작동한다. LLM 에이전트가 대체 불가능한 유일한 지점이며, 생성자와 **반드시 분리**되어야 한다.

### 3.3 교차 필터 구성

세 층을 병렬로 돌리면 결과가 서로 맞물리지 않는다. 앞 층의 출력이 뒤 층의 입력이자 검증 조건이 되는 **직렬 교차 필터**로 구성한다.

```
        [임상 실패 진술 + 제약조건]
                  │
                  ▼
    ┌─────────────────────────────┐
    │ Layer 1  분할 발견            │◄──┐
    │ 병변 분자 데이터 → 서브타입     │   │
    └─────────────────────────────┘   │
                  │ 후보 + 분할객체      │
                  ▼                    │
    ┌─────────────────────────────┐   │  분할 갱신
    │ Layer 2  대조 감독            │   │  (반복 루프)
    │ 약효 차이를 레이블로 판별       │───┘
    └─────────────────────────────┘
                  │ 특이성 라벨
                  ▼
    ┌─────────────────────────────┐
    │ Layer 3  직교 인과 정박        │
    │ 상관 → 인과 승격 / 기각        │
    └─────────────────────────────┘
                  │
                  ▼
            [근거 카드 출력]

    ═══ 횡단 ═══════════════════════
    Adversarial Evidence (전 층 상시)
```

**최소 요건**: Layer 1은 필수. Layer 2와 3은 **최소 하나 이상**. 셋 다 없으면 상관관계 나열에 그친다.

### 3.4 출력 스키마

에이전트가 채우는 것은 다음 한 문장의 빈칸이다.

> *"불응 환자 중 **[서브타입 S]**는 **[경로 P]**가 구동하며, **[바이오마커 B]**로 식별 가능하고, **[표적 T\*]**를 겨냥하면 반응할 것이다."*

이를 근거 카드로 구조화한다.

| 필드 | 내용 | 출처 강제 |
|---|---|---|
| 표적 후보 `T*` | 유전자/단백질 | Layer 1 |
| 서브타입 정의 `S` | 구동 환자군의 조작적 정의 | Layer 1 |
| 판별 바이오마커 `B` | S 식별 수단 (측정 가능해야 함) | Layer 1–2 |
| 적용 범위 | 질환 특이 / 계열 공통 | Layer 2 |
| 인과 근거 강도 | 추정치, 신뢰구간, 가정 위배 | Layer 3 |
| **반박 근거** | 실패 시험, 상반 데이터, 대안 해석 | Adversarial |
| 미충족 필드 | 근거 부재 항목 명시 | — |

> 💡 표적만 산출하는 것이 아니라 **그 표적을 시험할 환자를 고르는 방법까지 세트로** 나오는 것이 본 구조의 핵심 가치다. 이로써 가설이 반증 가능해지고, 후향 검증과 임상시험 농축(trial enrichment) 설계에 직접 연결된다.

### 3.5 에이전트 구성

| 에이전트 | 역할 | 접근 도구 |
|---|---|---|
| **Analyst** | 각 층 도구 호출, 파라미터 선택, 결과 1차 해석 | 계산 파이프라인, 데이터 저장소 |
| **Critic** | 반박 근거 능동 수집, 가정 위배 검사, 후보 기각 | 문헌·시험 DB, 전문 텍스트 독해 |
| **Arbiter** | 층 간 결과 충돌 조정, 신뢰 우선순위 판단, 최종 카드 작성 | 상위 요약 |

Critic 분리가 필수인 이유: 동일 에이전트가 후보를 생성하면서 동시에 반박하게 하면 자기 결론을 방어한다. 신약개발 맥락에서 확증편향은 치명적이다.

## 4. 설계 원칙

| # | 원칙 | 위반 시 결과 |
|---|---|---|
| 1 | 분할을 일급 객체로 전 층 전달 | 후처리 필터로 두면 Layer 1에서 이미 신호가 평균에 소실 |
| 2 | 순위화 목적 반전 | 근거 강도순 정렬은 이미 약이 나온 표적을 최상위로 올림 — 정답이지만 무용 |
| 3 | 출력 스키마 고정 (튜플) | 자유서술형 가설은 검증·반증 불가 |
| 4 | 계산층 / 판단층 분리 | 재현성과 신뢰성이 동시 붕괴 |
| 5 | 생성자 / 비판자 분리 | 확증편향으로 그럴듯한 오답이 상위 고정 |

### 원칙 2에 대한 부연

일반 에이전트는 근거 강도순으로 정렬한다. 문헌량과 경로 근거가 압도적인 후보가 상위에 온다. 그런데 **그 후보들은 이미 약이 존재하는 표적이다.** 맞는 답이지만 쓸모가 없다.

본 아키텍처는 "기존 약이 듣지 않는 이유를 설명해야 한다"는 제약이 걸려 있어, 근거가 가장 강한 후보를 능동적으로 배제해야 한다. **정렬 기준이 뒤집힌다.**

## 5. 이전(移轉) 요건

### 5.1 여섯 가지 조건

| # | 요건 | 왜 필요한가 | 미충족 시 |
|---|---|---|---|
| 1 | 진단명 아래 기전 이질성 | 나눌 것이 있어야 층화가 의미를 가짐 | 단일유전자질환 등은 층화 무의미 |
| 2 | 검증된 표적 + 부분 실패 | "불응"이 정의되려면 기준 약이 필요 | 약이 없으면 일반 표적 발굴이 적절 |
| 3 | **병변 조직 접근성** | 병변 부위 분자 데이터 확보 | **가장 빡빡한 관문** |
| 4 | 대조 집합 존재 | Layer 2 성립 | Layer 2 상실 |
| 5 | 직교 인과 증거원 | Layer 3 성립 | Layer 3 상실, 상관에서 멈춤 |
| 6 | 후향 검증 기준 | 에이전트 작동 여부 판별 | 성능 측정 불가 |

**요건 3이 실질적 관문이다.** 신경퇴행성질환이 이 아키텍처에 맞지 않는 이유가 여기 있다. 살아있는 뇌는 생검할 수 없다. 해당 영역의 기존 에이전트(예: ADAM-1)가 임상·미생물·문헌 RAG로 우회하는 것도 같은 제약 때문이다.

### 5.2 질환별 적합도

| 질환 | Layer 1 | Layer 2 | Layer 3 | 검증 기준 | 종합 |
|---|---|---|---|---|---|
| **염증성 장질환** | 장 점막 종적 아틀라스 (치료 전후 짝지음) | CD vs UC, 관해 vs 비관해 | IBD GWAS (검정력 우수) | OSM 등 기지 결과 | **최적합** |
| **류마티스 관절염** | 활막 scRNA-seq (AMP RA) | 관절염군 간 약효 분기 | RA GWAS × pQTL | R4RA | 적합 |
| **루푸스(SLE)** | 신장 생검 (AMP SLE) | 시험 성패 대조 | SLE GWAS | 제한적 | 적합 (조직 접근이 신염에 국한) |
| **천식/COPD** | 기관지·유도객담 | T2-high/low | 중간 | 기존 층화 성공 사례 | 양성 대조군으로 적합 |
| 신경퇴행성질환 | ✗ 조직 접근 불가 | — | — | — | 부적합 |
| 희귀 단일유전자질환 | ✗ 이질성 부재 | — | ✗ GWAS 검정력 부재 | — | 부적합 |
| 대부분의 고형암 | ○ | ○ | ○ | ○ | 이미 성숙 — 신규성 낮음 |

빈칸이 있는 질환은 배제 대상이 아니라 **해당 층의 구현체를 다른 것으로 채워야 하는 질환**이다.

### 5.3 실행 순서 권고

1. **IBD에서 파이프라인 구축** — 데이터 요건이 가장 잘 갖춰짐. 기지 결과(OSM 등) 재현으로 작동 입증
2. **동일 구조를 RA로 이식** — 층 구현체만 교체하여 이전 가능성 검증
3. **천식으로 양성 대조** — 이미 확립된 층화를 독립 재발견하는지 확인

리스크 대비 실익이 가장 좋은 경로다. RA를 먼저 택할 경우 §7.1의 라벨 문제를 정면으로 맞게 된다.

## 7. 한계와 미결 사항

### 7.1 불응 라벨의 조작적 정의

공개 데이터에 "치료 불응" 라벨이 균일하게 붙어 있지 않다. 대응 옵션:

1. 라벨이 존재하는 소규모 층화 시험 데이터로 이동 — 표본 수 희생
2. Layer 2의 무게중심을 자매 질환 비교로 이동 — 환자별 반응 라벨 불필요
3. 대리 지표 정의 — 조직 병리형·질병활성도로 대체
4. **IBD처럼 종적 짝지음 데이터가 있는 질환 선택** — 문제 자체가 소멸

### 7.2 주장 크기의 설정

> ⚠️ 에이전트 위상(멀티에이전트 구성, 도구 호출, 크리틱 루프) 자체는 새롭지 않다. 기존 표적 가설 에이전트에 그대로 얹을 수 있다. **아키텍처 수준에서는 새 패러다임이 아니라 특화(specialization)다.**
>
> 방어 가능한 기여 진술: "새 에이전트 아키텍처를 제안한다"가 아니라 **"표적 발굴 문제를 환자 층화 문제로 재정의하고, 그에 맞는 출력 스키마·순위화 제약·층 역할 정의를 설계한다"**.

아키텍처 신규성이 별도로 요구될 경우 추가 가능한 요소:

- 분할 객체를 층 간에 갱신·전달하는 상태 구조 (stateful partition object, §3.3의 반복 루프)
- Critic이 "이 표적의 과거 실패 이력이 현재 관찰된 불응 패턴과 모순되는가"를 능동 검사하는 전용 루프

### 7.3 미결 사항

1. **주력 출력 결정** — 서브타입 / 표적 / 바이오마커 중 1순위 산출물
2. **목적 확정** — 방법론 검증(논문) vs 실제 자산 발굴. §5.3의 진입 질환 선택이 여기 연동
3. **데이터 접근 실사** — 각 데이터셋의 승인 요건, 실제 표본 수, 주석 수준
4. **계산 파이프라인 사양** — 결정론적 층의 도구 선정 및 버전 고정

# 부록 A. 사례 연구 — 류마티스 관절염

## A.1 문제 상황

RA는 검증된 표적(TNF-α, IL-6, IL-17/IL-23, JAK, CD20, CTLA4-Ig)과 활발한 파이프라인을 이미 갖췄다. 2026년 현재 RA 파이프라인은 역대 가장 기전적으로 다양하다는 평가를 받는다.

| 갈래 | 성격 | 사례 |
|---|---|---|
| 기존 표적 개량 | 표적 유지, 분자 개선 | zemprocitinib (LNK01001) — 차세대 경구 JAK 억제제, 2026년 1월 3상 1차·주요 2차 지표 충족 |
| 기존 표적 + 새 양식 | 표적 유지, 접근법 전환 | CD19 CAR-T, 이중·삼중특이항체. Kali Therapeutics의 CD19/BCMA/CD3 삼중특이항체 KT-501이 2026년 3월 사노피에 12억 달러 규모 라이선싱 |
| 신규 표적 | 새 기전 | BTK 억제제, PD-1 경로 작용제 등 (소수) |

세 갈래 모두 최종 지향점은 동일하다 — **기존 생물학적제제 불응 환자군**. 첫 TNF 억제제에 충분히 반응하지 않는 환자는 대략 3분의 1 수준이다.

## A.2 층 구현체

| Layer | 구현체 | 접근 |
|---|---|---|
| 1 | AMP RA/SLE 활막 scRNA-seq · bulk RNA-seq · mass cytometry | ImmPort **SDY998, SDY999** (SLE는 SDY997) |
| 1 | AMP RA Phase 2 확장 단일세포 멀티오믹스 | immunogenomics.io/ampra2 |
| 1 | RA Atlas CITE-seq (코드 포함) | GitHub `immunogenomics/RA_Atlas_CITEseq` |
| 1 | PEAC 초기 관절염 코호트 활막 RNA-seq | 공개 포털 |
| 2 | 질환별 공개 전사체 | GEO |
| 2 | ImmuNexUT — 다수 자가면역질환 면역세포 분획, 동일 플랫폼 | 공개 |
| 2 | 임상시험 결과 대조 | ClinicalTrials.gov / AACT |
| 3 | RA 대규모 다인종 GWAS 요약통계 | 공개 |
| 3 | UK Biobank 혈장 단백체(UKB-PPP) pQTL, deCODE, eQTLGen | 공개 요약통계 |

Layer 3 자원이 전부 공개 요약통계라는 점이 중요하다. 개인정보 승인 절차 없이 인과 추론이 가능한, 사실상 유일한 경로다.

## A.3 검증 기준 — R4RA

R4RA는 TNF 불응 RA 환자(n=164)의 활막을 생검해 층화한 최초의 생검 기반 다기관 무작위 시험(4상, open-label)이다.

- **분류 기준**: CD3⁺ T세포, CD20⁺ B세포, CD68⁺ 대식세포, CD138⁺ 형질세포 반정량 점수 → lymphomyeloid / diffuse-myeloid / fibroid(pauci-immune) 병리형
- **핵심 결과**: 활막 B세포 분자 시그니처가 낮은 환자에서 **리툭시맙 반응률 12% vs 토실리주맙 50%**
- **부가 결과 1**: 조직학적 분류보다 **분자적(유전자 발현) 분류의 반응 예측력이 더 높았다**
- **부가 결과 2**: 전 치료 불응 환자에서 **기질/섬유아세포(stromal/fibroblast) 시그니처** 확인

> 마지막 항목이 §1.2 ①의 실증이다. 층화하지 않았다면 이 표적 계열은 관측되지 않았다. 층화가 표적 발굴의 진입로라는 명제의 근거다.

## A.4 이 사례의 약점

AMP RA 샘플 상당수는 치료 이력·반응 여부가 정밀하게 주석되어 있지 않다. §7.1의 라벨 문제를 정면으로 맞는 사례다.

# 부록 B. 사례 연구 — 염증성 장질환

## B.1 왜 최적합인가

여섯 요건을 모두 충족하며, 특히 RA에서 막혔던 부분이 열린다.

| 요건 | 충족 근거 |
|---|---|
| 기전 이질성 | 확립됨 |
| 검증 표적 + 부분 실패 | 항TNF, 우스테키누맙, 베돌리주맙, JAK 등 존재. 1차 무반응 상당 비율 |
| 병변 조직 접근성 | **대장내시경 생검이 일상 진료의 일부** |
| 대조 집합 | 크론병 vs 궤양성 대장염 (약물별 효능 분기), 관해 vs 비관해 |
| 인과 증거원 | IBD GWAS는 검정력이 가장 좋은 축에 속함 |
| 검증 기준 | OSM 등 기지 결과 |

## B.2 데이터 자산

- **종적 치료 아틀라스** — 아달리무맙 치료 전후를 짝지은 단일세포 데이터. 41명, 216개 생검, 약 100만 세포, 109개 세포 상태. **치료 전 상피·골수계 차이가 관해 결과와 연관**됨이 확인됨. 종적 비교에서 비관해 시 CD는 골수계·T세포 교란, UC는 다세포 IFN 신호 증가
- **IBDverse** — 말단 회장 생검 단일세포 아틀라스. 크론병 111명 + 건강 대조 232명, 110만 세포. 염증성 단핵구·대식세포를 질병 감수성에 연루
- **UC 조직 아틀라스** — CODEX 면역형광, 29명 UC + 5명 대조, 42개 조직 영역, 52개 바이오마커, 171만 세포. **성별 의존적 차이 및 TNF 억제제 저항성** 관련 소견 포함
- GSE214695 등 GEO 공개 데이터셋

## B.3 기지 결과 — OSM

**OSM(oncostatin M)**은 IBD 바이오마커이자 치료 표적으로 제안되어 있다. 기질 염증 프로그램(IL6, CXCL9, CXCL10 포함)을 유도하며, **치료 전 높은 수치가 항TNF 실패와 연관**된다.

> 이는 정확히 본 아키텍처가 산출하려는 출력 튜플의 형태다 — 서브타입(OSM 고발현군) · 경로(기질 염증 프로그램) · 바이오마커(치료 전 OSM 수치) · 표적(OSM 축). 후향 재현 검증의 1순위 대상으로 적합하다.

## B.4 추가 이점

RA에서 데이터 부재로 차단됐던 **내성 기전 축(2차 실패 분석)**이 IBD에서는 열린다. 치료 전후 짝지은 종적 샘플이 공개되어 있기 때문이다.

| # | 상황 | 가설 형태 | 요구 데이터 | 공개데이터 실현성 |
|---|---|---|---|---|
| ① | 1차 치료 실패 | "불응군은 단일 집단이 아니라 X가 주도하는 별개 서브타입이다" | 병변 오믹스 | **높음** |
| ② | 약 선택 불가 | "바이오마커 B 고발현 환자는 약물 D에 반응한다" | 오믹스 + 반응 라벨 | 중간 (RA) / **높음** (IBD) |
| ③ | 전 치료 불응 | "모든 약에 저항하는 군에 특이 활성 경로 P가 있다" | 병변 오믹스 + 불응 라벨 | 중간~높음 |
| ④ | 타 질환의 성공 기전 | "질환 X의 기전·양식 M을 이식하면 동일 축을 더 강하게 차단한다" | 문헌 + 약물 DB | **높음** |
| ⑤ | 계열 내 약효 분기 | "약물 M이 질환 A엔 유효하고 B엔 실패한 분자적 요인은 무엇인가" | 질환 간 비교 오믹스 + 시험 결과 | **높음** |
| ⑥ | 2차 실패(내성) | "항약물항체인가, 보상 경로 활성화인가" | 종적 짝지은 샘플 | 낮음 (RA) / **높음** (IBD) |
| ⑦ | 발병 전 개입 | "고위험 무증상자에 조기 개입하면 발병을 막는가" | 발병 전 코호트 | 낮음 |

본 아키텍처는 ①③을 Layer 1로, ⑤(및 ②⑥)를 Layer 2로 흡수한 구성이다. ④는 독립 실행 가능하며 문헌 기반 에이전트(Robin 계열)의 영역에 가깝다. ⑦은 데이터 요건상 현 단계에서 제외.
